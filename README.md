# Daymark — Academic Planner

A dark, Notion-inspired **single-page** academic workspace built with static HTML, CSS and JavaScript. All sections live on one continuous scrolling page.

## Features
- Mountain cover and quick-action buttons
- Course gallery with course-linked assignments and completion summaries
- Tasks and assignments with priorities, due dates and projects
- Interactive month calendar, weekly planning and upcoming deadlines
- Personal dashboard, projects and notes
- 25-minute study focus timer
- JSON backup export/import

## Live site
https://spsam1903-beep.github.io/personal-planner/

GitHub Pages settings: **Settings → Pages → Deploy from a branch → main → /(root)**.

## Data and privacy
All content is stored in your browser using `localStorage`. This is not a cloud-synced account; different browsers and devices have separate data, and clearing browser data could remove it. Export backups regularly from **Workspace settings**. Importing a backup replaces local planner data.

The cover image loads from Unsplash. This version doesn't include Google Calendar syncing or notifications. The focus timer runs while the webpage remains open.
