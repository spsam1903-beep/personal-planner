# Daymark — Personal Planner

Personal productivity dashboard built with HTML, CSS and JavaScript, no build tools needed.

## Features
- Dashboard for today's tasks and deadlines
- Calendar with month, week and day views
- Add, edit, complete and delete tasks with due dates, priorities, categories and projects
- Projects with progress tracking
- Weekly planner and notes
- Dark mode and JSON backup export/import

## Publish with GitHub Pages
1. Go to repository **Settings → Pages**.
2. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
3. Choose branch **main**, directory **/(root)** and click **Save**.
4. Visit https://spsam1903-beep.github.io/personal-planner/ once GitHub Pages finishes publishing.

## Data storage
All information lives in this browser's `localStorage`, not in GitHub. It does not sync across browsers/devices. Clearing browser data may erase the planner. Use **Settings → Export backup** regularly; importing replaces the current data.

Google Calendar syncing and notifications are not included in this first version.
